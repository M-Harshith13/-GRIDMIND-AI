demand_hourly.csv contains timestamp and load_kw. The original one-minute
Global_active_power readings (kW) were grouped by hour using their mean. Missing
hourly values are linearly interpolated for the model's rolling lag features.
The model and microgrid assets are a local demonstration; the data are historical
measurements from one household and are not live utility telemetry.
